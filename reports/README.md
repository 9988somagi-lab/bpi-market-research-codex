## 数据边界

服务机器人仅使用World Robotics2026同批次数据，238家供应商样本不外推全行业；不同调查波次不拼接。应用增长量由2025数量和已四舍五入同比反推，不是原始2024实绩。区域、应用和中国本土/外资供应商份额有明确分母；无统一销量分母的品牌份额不绘制。

2026–2029工业安装为IFR预测；2035人形TAM是Goldman Sachs2024发布的旧版预测。IFR全尺寸人形窄口径（>140cm、专业商业用途）不能代表所有人形产品。固定工业机器人安装量不能直接变成电池需求。

贸易图只保留H6/HS2022和非区域汇总，按本次可用报告国排序，不是完整全球榜。HS847950不覆盖全部具身机器人，HS850760无法单独识别机器人用途。数量单位和估算标识保留；缺失不得视为零。企业部署和生产数据注明厂商自述，不能当作份额或全部外售量。

PPT每页有来源ID，备注及最后三页提供可点击原始URL。BPI客户顺序、产品路线、行动KPI与收入模型均为建议或明确假设。
