## 事实与模型边界

- RAK9155原厂明确4颗50Ah电芯串联，因此4S1P为产品事实。RAK9154组数表述有歧义，3S2P只是工程候选，P未确认。
- Particle MSDS给3.7V、1800mAh、6.66Wh；优先于网页不一致Wh。单节平台不能证明所有兼容电池包的内部并联数。
- HS850650为广义一次锂电池，不是纯IoT；qty单位5、非估算数量仍不是统一单体当量。原始API状态字段保留。国家样本不能直接相加成为全球需求。
- **本次资料不足以核实全球IoT电池实际年度出货及化学体系份额。M01不是经验证的市场预测。** b=5/10/20%、寿命1/3/5年、等批量10万包和未来组合均为明示假设；中间连接年份为作者插值。
- 新增连接配套不包含所有整机更新、换电、备件与短距离IoT。维护与整机更新必须去重。模型数量不代表BPI订单，不用于直接扩产或承诺备货。
- 其他市场、历史采用率与贸易数据沿用原口径：2026未结束；F为预测；Eurostat采用率为2021；HS编码不单独隔离IoT；连接、出货、收入、贸易与订单分别管理。
